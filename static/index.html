RaceTime

chip-free race timing

Three screens, one database. Set the race up on a laptop, put a phone on every checkpoint, and let anyone follow along.

Race admin

Create the race, mark your checkpoints, load the start list, upload your artwork and print branded bibs.

Checkpoint

For volunteers. Scans bibs with the phone camera and keeps recording with no signal. Open this on each checkpoint phone and add it to the home screen.

Live results

Public leaderboard and splits. Share the link with the event code on the end.

Finisher certificate

For runners. Enter a bib and get a printable certificate with the finish time, position and splits, on the race artwork.
